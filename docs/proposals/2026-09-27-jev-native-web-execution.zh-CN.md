# 提案：Jev 辅助的 Native 网页目标执行

[English](2026-09-27-jev-native-web-execution.md) | 简体中文

**状态：已暂停的提案。** 用户于 2026-09-27 因普通网站上的实际效果不理想而暂停此方向。实验代码不在 `main`；本文仅供审阅，不授权继续实施、测试或合并[实验分支](https://github.com/luobosibing2/dsh-jev-plugin/tree/codex/jev-native-web-execution)。

## 直接答案

这个可选 Jev 功能拟协助 DSH 主 Agent 在已经选定的网页上执行目标。主 Agent 提供目标、页面标识、约束和需要填写的内容；插件通过 DSH 现有 Native Computer Use 工具观察该页面，从当前观察构造可执行候选，请 Jev 选择一个候选，每轮最多执行一个动作，并把证据与有界结果交回主 Agent。Jev 只在已观察的动作中选择，不生成填写内容、不虚构目标、不裁定整个目标已经完成，也不取代主 Agent。

## 问题与已观察限制

已暂停的实验暴露了三个相关问题。对每个 pointer 引用展开滚动动作，消耗了 80 个动作候选预算中的大量名额，使可见的搜索控件落在截断位置之外；无名链接可能在缺少目标证据时被选中；重复观察与不清晰的交接使主 Agent 反复处理相同状态。这些观察支持改进候选质量、状态表达和停止规则，尚不能证明改进后的功能能提高真实网站任务的完成效果。

实验所见的 Native 引用提供动作能力、frame、名称、引用、角色、状态、值和可见性，但没有可靠的父子关系、链接目标或元素边界。将来若继续实施，必须先重新核对当前 Native 接口，才能使用新增字段。

## 拟议行为

- **范围与所有权。** 功能保留在此独立插件中，默认关闭，按 profile 启用。只处理 live Web 根会话中明确交接的任务页面。沿用宿主已注册的 Native 工具及其授权规则；不修改 DSH、不启动第二套浏览器驱动、不选择无关标签页，也不拦截普通 Native 调用。
- **观察与候选。** 在普通模型可见的工具正文中提供对交接页面的有界只读观察。只从同一次当前 Native 观察和主 Agent 提供的文本构造候选。先过滤不支持、禁用、不可见或说明不足的动作，再分配候选预算。优先保留可操作输入框与有名称的控件，并为滚动设置独立的小额度。不因名称相同而合并不同 Native 引用，不推断缺失的父子关系或 URL，也不提交目标说明已被省略的动作。
- **Jev 判断。** 向公共 Jev 服务发送目标、可用证据、可执行候选和实际结果的紧凑历史。只接受同一判断轮次的合法候选。传输故障或无效回答沿用人工 Retry/Cancel；合法的业务 `unknown` 交回主 Agent，通过 Native 继续处理。
- **执行与上限。** 每次判断最多执行一个选中动作，然后观察结果。若仍有效，下一轮直接复用这次动作后的观察。总轮次、无进展次数及连续 observe 均有上限；取消后迟到的结果不能引发后续动作。不能执行过期引用、在 Native 拒绝后自动改为前台输入，或重放效果不确定的写操作。填写内容只有在完整交付且唯一字段读回吻合后才视为已填。
- **交接与记录。** 返回页面标识、最后观察及覆盖限制、已尝试动作、已核实效果和明确的结束原因。完成建议仍由主 Agent 核验。记录候选数量、省略原因、判断、字段读回，以及可计量的观察、Jev 和执行耗时；不重复相加有包含关系的耗时，也不归因未测量的等待。模型可见结果须能从 DSH Session 重建；辅助 Jev 判断进入插件账本。

## 考虑过的替代方案

**只提高 80 个动作的上限。** 这会保留重复滚动与说明不足的链接，同时向 Jev 发送更多候选。先过滤候选并单独分配额度，才直接针对已观察到的遗漏。

**用 DOM/CDP 浏览器方案替换 Native。** Browser-use 和 agent-browser 提供更丰富的元素关系，但引入它们会增加第二套观察与执行所有者，并假设已观察的 Native 接口没有提供的字段。

**加入截图猜测、第二个规划模型或自动前台回退。** 这些做法扩大功能权限，还可能重复效果不确定的写操作。插件无法处理的情况由现有主 Agent 和 Native 工具负责。

**只靠置信度控制动作。** 阈值无法找回根本没有进入候选集的搜索按钮。

## 验收条件

- 功能关闭或主 Agent 直接使用普通 Native 工具时，插件不请求 Jev，也不改变 Native 参数、结果、权限或运行时所有权。
- 在同样的 80 个动作预算下，原先产生重复滚动候选的页面仍保留已观察到的搜索输入框与提交控件。证据不足的无名目标不会被盲选；名称相同但引用不同的控件仍保留各自身份。
- 输入完整交付并经唯一字段读回后，下一轮判断表达为已填写，不再提出相同替换。未确认的写操作保持不确定状态，不为诊断而重放。
- 空白或未绑定页面、缺少填写内容、动作不支持、业务 `unknown`、引用过期或进展预算耗尽时，主 Agent 收到具体交接原因及可用的当前证据。只读观察不请求 Jev，并在下一轮模型可见内容中展示真实 Native 引用。
- 聚焦测试覆盖公开工具路径、生命周期、失败与取消、Session 输出和候选统计。真实普通网站试验另以固定任务与主模型比较纯 Native 和 Native 加 Jev 的完成证据、主模型／Jev／CUA 调用次数及墙钟时间。模拟运行不能满足这一效果验收。

## 边界与验证

实验分支保留了本地回归与隔离 Native 流程证据，包括候选保留和模型可见引用交接。但用户因实际效果不理想而暂停了实验；普通网站完成效果、性能收益以及真实主模型与 Jev 的联合验收仍未验证。本 PR 只发布提案，不修改已发布插件，也不恢复实验。以后若继续实施，需要新的恢复决定、重新核对当前 DSH Native 接口，并完成上述真实网站验收。凭据、本机 profile 和原始用户会话均不属于本提案。
