## 直接答案

技能选择和文件排序已通过确定性测试及隔离 DSH Web 的原生流程检查。历史选择功能验收的一组命令报告 7 个测试文件、52 项通过；这是整组测试数，不是这两项各自的用例数，也不是任务效果评分。Web 场景使用本地确定性 Jev 应答，验证插件接线、展示和再次判断；没有启用前后的任务成功率或耗时对照。

本页公开的是已观察到的场景和结果，不包含原始 Session、个人测试目录、凭据或截图。

## 技能选择

在隔离 Web 检查中，目录有 7 个可供模型调用的技能摘要，Jev 选择后向主模型发布 5 个，并保留查看完整目录的入口。测试还检查判断请求只包含技能名称和摘要，不发送技能正文；未列出的技能仍可通过原生路径调用。再次发起符合条件的请求会重新判断，不复用上次排序答案。实现与确定性断言见[技能选择测试](../../../packages/jev/tests/selection.test.ts#L137)和[包说明](../../../packages/jev/README.md)。

这次观察说明模型可见摘要由 7 个变成 5 个，不能据此计算节省的模型输入量、任务成功率或查找时间。主模型是否加载某项技能，仍由主模型决定；该次 Web 场景没有让真实主模型自主完成任务。

## 文件排序

确定性测试构造 `alpha.ts` 与 `beta.ts` 两个候选，给出 0.1 与 0.9 的模拟相关概率，原生 `glob` 结果按概率把 `beta.ts` 排到前面；40 个命中可进入判断，超过配置上限的 41 个命中则走原生结果。参见[原生 glob 排序测试](../../../packages/jev/tests/selection.test.ts#L187)、[数量边界测试](../../../packages/jev/tests/selection.test.ts#L293)及[PTC 结果传递测试](../../../packages/jev/tests/selection-ptc.test.ts#L41)。

隔离 Web 场景中，原生 `glob` 找到 7 个 TypeScript 路径，本地确定性 Jev 给每条相同的 0.75 分数，结果展示了这 7 条路径和分数；再次搜索会发起新的判断。由于 7 条得分相同，这个场景只证明分数与路径经过了原生工具流程，不证明实际相关性排序改善。没有找文件耗时或任务结果的前后对照。

## 边界与验证

本地确定性应答验证排序、默认限制、展示和生命周期，不测真实 Jev 的语义准确率。7 取 5 是一次摘要数量变化，0.9、0.1 和 0.75 是测试应答中的概率，不是生产环境准确率。真实模型是否更快找到合适技能或文件，目前效果尚未量化；仓库总体口径见[验证说明](../../validation.md)。
